## 🔥 NOW YOUR TURN - 3 SIMPLE STEPS:

### **STEP 1: RENDER DATABASE (2 min)**

```
1. Open: https://render.com/dashboard
2. New + → PostgreSQL
3. Name: ludo-carrom-db
4. Database: ludo_carrom
5. User: ludouser
6. Region: Singapore
7. Plan: Free
8. Create
9. Copy Database URL
```

**⏱️ Time: 2 minutes**

---

### **STEP 2: RENDER BACKEND (3 min)**

```
1. Open: https://render.com/dashboard
2. New + → Web Service
3. Select: Cashwinludo
4. Fill:
   - Name: ludo-carrom-api
   - Root: backend
   - Build: npm run build
   - Start: node dist/server.js
5. Add these variables:

NODE_ENV=production
PORT=5000
DATABASE_URL=[YOUR_DB_URL]
JWT_SECRET=ludo-carrom-secret-2024
JWT_REFRESH_SECRET=ludo-carrom-refresh-2024
ADMIN_EMAIL=admin@ludocarrom.com
ADMIN_PASSWORD=admin123
PAYMENT_BKASH_NUMBER=01700000001
PAYMENT_NAGAD_NUMBER=01700000002
PAYMENT_ROCKET_NUMBER=01700000003
WELCOME_BONUS=20
REFERRAL_BONUS=50
WITHDRAWAL_CHARGE_TYPE=fixed
WITHDRAWAL_CHARGE_VALUE=5
CORS_ORIGIN=https://ludo-carrom.vercel.app
MAINTENANCE_MODE=false
LUDO_ENABLED=true
CARROM_ENABLED=true

6. Deploy
7. Wait 3 minutes
8. Go to Shell → npm run migrate
9. Copy Backend URL
```

**⏱️ Time: 3-5 minutes**

---

### **STEP 3: VERCEL FRONTEND (2 min)**

```
1. Open: https://vercel.com/dashboard
2. Add New → Project
3. Select: Cashwinludo
4. Root Directory: frontend
5. Add these variables:

NEXT_PUBLIC_API_URL=https://ludo-carrom-api.render.com
NEXT_PUBLIC_SOCKET_URL=https://ludo-carrom-api.render.com

6. Deploy
7. Wait 2 minutes
8. Copy Frontend URL
```

**⏱️ Time: 2-3 minutes**
